PER-FIELD INSTRUCTIONS — read carefully before extracting.

unit_id  (string | null, OPTIONAL)
  WHAT:  The literal apartment/unit identifier from the API.
  DON'T: Confuse with floorplan IDs, property IDs, or numeric primary keys
         that are not the apartment number. If unsure, leave null.

floor_plan_name  (string | null, REQUIRED for every record)
  WHAT:  Human-readable plan name.
  DO:    When the KNOWN FLOOR PLANS list above is populated and a record's
         beds/baths/sqft match one of those plans, prefer that canonical
         name. Otherwise use the API's literal value.
  DON'T: Copy a canonical name onto a record whose beds/baths/sqft do not
         match. Reject CMS module identifiers (MODULE_*, WIDGET_*,
         "Lease Magnet", "Pop-Up") — those are not floor plans.

floor_plan_source  (enum, REQUIRED when floor_plan_name is non-null)
  "page_label" | "section_heading" | "url_slug" | "inferred" | null.

bedrooms / bathrooms / sqft  (numbers)
  Studio = 0. Half-baths = 0.5. Strict numeric extraction.

market_rent_low / market_rent_high  (numbers)
  USD per month. Range → low + high. Flat rent → both equal.

availability_status  (enum)
  Map API values to AVAILABLE | UNAVAILABLE | WAITLIST | UNKNOWN.

availability_count  (integer | null)
  WHAT:  Per-floor-plan availability count when the API exposes it
         (e.g. {"floor_plan": "Aspen", "available": 5}).
  DON'T: Fabricate per-unit records to inflate the unit count.

amenities  (array of lowercase strings)
  See AMENITIES block below.

concession_text / concession_value / concession_source
  See CONCESSIONS block below.

property_amenities  (top-level array)
  Union of all amenity strings found, lowercased and deduplicated.

AMENITIES (observation-only — extract if present, do not fabricate)
  WHAT:  Pool, fitness center, dog park, pet friendly, parking, EV charging,
         business center, package room, clubhouse, in-unit washer/dryer,
         balcony, etc.
  WHERE: API fields named amenities, features, community_features,
         unit_features. May be at root level or nested.
  DO:    Lowercase, deduplicate, return as a flat array. Aggregate into
         property_amenities at the top level.
  DON'T: Fabricate. Don't emit marketing copy, addresses, or office hours.

CONCESSIONS (observation-only — extract if present, do not fabricate)
  WHAT:  Rent discounts (e.g., "1 month free", "$500 off first month").
  WHERE: API fields named concession, discount, promotion, special. May be
         a structured object with amount/months/description, or freeform
         text.
  DO:    concession_text = human-readable description (verbatim).
         concession_value = numeric dollar amount when extractable.
         concession_source = "api_field" or "description_text".
  DON'T: Fabricate. Don't infer concessions from rent ranges.

GENERAL RULES:
- Extract ALL units/floor plans, not just a sample.
- Use the EXACT key names from the JSON for json_paths; dotted notation for
